# Requirements  
1. It accepts an audio file, and .ogg is supported.  
2. It transcribes the speech to text.  
3. The text appears in a field the user can copy from.  
4. The user can export it as .md or .txt.  
5. It is written in Rust only.  
6. It is one Windows executable.  
7. The model is chosen in the app, and the models are built in.
